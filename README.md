# gestaoVeiculos

Sistema de aluguel de veículos desenvolvido para o trabalho avaliativo de
Padrões de Projeto (Padrões Criacionais) — IFMS.

## Padrões utilizados
- Factory Method
- Abstract Factory
- Builder
- Prototype
- Singleton

Detalhes do domínio em [docs/TEMA.md](docs/TEMA.md).
Detalhes dos padrões em [docs/PADROES.md](docs/PADROES.md).

## Como executar
1. Instalar as dependências: `npm install`
2. Executar o sistema: `npm start`
